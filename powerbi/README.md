# 📊 Power BI Dashboard

The Power BI dashboard was created to analyze customer shopping behavior and identify key business trends.

## Dashboard Analysis

The dashboard focuses on:

* Customer purchasing behavior
* Revenue analysis
* Subscription performance
* Product performance
* Customer segmentation
* Discount usage
* Purchase trends

## Power BI File

The original `.pbix` file was created using Microsoft Power BI Desktop.

Due to GitHub file handling limitations, the `.pbix` file is not included in this repository. The dashboard preview and analysis are available through the screenshots provided in this project.
