# 🛍️ Customer Shopping Behavior Analysis

### End-to-End Data Analytics Project using Python, MySQL & Power BI

An end-to-end data analytics project focused on understanding customer shopping behavior, purchasing patterns, product performance, discounts, subscriptions, and customer segments.

---

## 📌 Project Overview

This project analyzes customer shopping data to transform raw transactional data into meaningful business insights.

The complete workflow covers:

**Raw Data → Python/Pandas → MySQL → SQL Analysis → Power BI Dashboard**

The project demonstrates how different data analytics tools can be combined to perform data cleaning, transformation, business analysis, and visualization.

---

## 🎯 Business Objective

The main objective is to understand:

* Customer purchasing behavior
* Revenue contribution across customer groups
* Impact of discounts on purchasing
* Subscriber vs non-subscriber behavior
* Product ratings and product performance
* Shipping preferences and spending
* Customer loyalty and segmentation
* Most purchased products within categories

## 🐍 Data Cleaning & Transformation

Python and Pandas were used for data preparation.

### Key steps:

* Loaded the raw CSV dataset using Pandas
* Inspected dataset structure and data types
* Checked missing values
* Handled missing `Review Rating` values using category-level median imputation
* Standardized column names
* Renamed `purchase_amount_(usd)` to `purchase_amount`
* Created age groups using quartile-based segmentation
* Converted purchase frequency categories into approximate days
* Compared `discount_applied` and `promo_code_used`
* Removed the redundant `promo_code_used` column
* Prepared the cleaned DataFrame for MySQL analysis

## 🗄️ MySQL & SQL Analysis

The cleaned data was loaded into MySQL and analyzed using SQL.

### Business questions explored:

1. What is the total revenue generated by male vs female customers?
2. Which customers used a discount but still spent more than the average purchase amount?
3. Which products have the highest average review ratings?
4. How does average spending differ between Express and Standard shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which products have the highest percentage of discounted purchases?
7. How many customers fall into New, Returning, and Loyal segments?
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?

### SQL concepts demonstrated:

* `GROUP BY`
* Aggregate functions
* `CASE`
* `HAVING`
* Subqueries
* Common Table Expressions (CTEs)
* `ROW_NUMBER()`
* `PARTITION BY`
* Conditional aggregation
* Sorting and filtering
* Business-oriented SQL analysis

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Govil-Tyagi/customer-shopping-behavior-analysis.git
```

### 2. Open the Jupyter Notebook

Navigate to:

```text
python/customer behavior analysis (1).ipynb
```

Make sure the raw dataset is available at:

```text
data/raw/customer_shopping_behavior.csv
```

### 3. Set up MySQL

Create the database and load the cleaned dataset into the `customer` table.

### 4. Run SQL Analysis

Open:

```text
sql/customer_analysis.sql
```

and execute the queries in MySQL.

### 5. View the Power BI Dashboard

Open the dashboard created in Power BI Desktop and explore the visualizations.
